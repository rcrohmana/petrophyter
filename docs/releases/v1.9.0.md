# Petrophyter v1.9.0

Petrophyter v1.9.0 adds uncertainty analysis. HCPV and net pay become a range instead of one number: you define distributions for the saturation parameters and the cutoffs, and a Monte Carlo run reports P90, P50 and P10 for the field, each well and each zone, with a histogram, an exceedance curve and a tornado. It is optional: **until you enable a distribution, results, exports and saved sessions are the same as in v1.8.0.**

## New

- **Uncertainty tab** (after Summary).
  - **Table.** For the selected metric (HCPV net pay, HCPV net reservoir, net pay, average PHIE in pay, average Sw in pay): P90, P50, P10, mean, the deterministic value, the number of valid realisations and the probability of zero net pay, for the field, each well and each zone. P90 is the low case, exceeded with 90 % probability; P10 is the high case. The field row comes from the per-realisation field totals, not from adding well percentiles.
  - **Histogram and exceedance curve** for the selected row, with P90, P50, P10 and the deterministic value marked.
  - **Tornado** for HCPV net pay and net pay: each parameter at the 10th and 90th percentile of its own distribution with the others at their base values, sorted by swing, with the rank correlation of each parameter with the field result.
  - **Diagnostics.** The share of draws clipped to the physical limits of each parameter, the probability of zero net pay per well, wells that could not be evaluated and why, and a warning when the percentiles are not converged at the chosen N.
  - **Out of date.** A chip appears when a well's parameters or the uncertainty setup changed since the run; the result stays readable.
- **Parameters → Uncertainty.** One distribution per parameter (a, m, n, Rw, Rsh and the Vsh, PHIE and Sw cutoffs): triangular, normal (truncated at three standard deviations) or uniform, as a relative or additive offset from the resolved value of every well and zone, so scopes, presets and automatic estimates are kept. **Suggested ranges** fills typical triangular ranges and enables nothing. N (50 to 5000, 300 by default), seed, **New seed**, Latin hypercube or random sampling, and a rank correlation between m and n (default 0).
- **Analysis → Run Uncertainty…** and **Analysis → Stop Monte Carlo**. The run uses the current parameters, shows its progress in the status bar, and does not block the window. It is refused while an analysis run is in progress; New Project and Load Session cancel it, and closing the window asks before quitting.
- **Exports.** The Excel workbook gets an **Uncertainty** sheet (header with seed, N, sampling, convention and out-of-date flag; P90, P50, P10, mean, standard deviation, minimum, maximum, valid count, probability of zero and deterministic value for the field, each well and each zone) and a **Tornado** sheet when a result exists. CSV and LAS are unchanged.
- **Reproducible.** The same seed, N, sampling and ranges give the same numbers.

## Sessions

- A session with at least one enabled distribution is saved as format **2.3**, with the distributions, N, seed, sampling and correlation. The result is not saved: run again and the seed regenerates it. A session without an enabled distribution is saved as before (2.2 with rock typing, otherwise 2.1).
- Sessions from earlier versions load with nothing enabled. **A 2.3 session opens in v1.8.0 and v1.7.x without the uncertainty setup**, and saving it again there drops it.

## Calculation changes

- None to existing results; every reference case is unchanged relative to v1.8.0.
- Simandoux with an exponent n other than 2 is now solved for all samples at once instead of one sample at a time. The results are identical; a 10 000-sample well takes about 6 ms instead of about 200 ms.

## Quality

- The Monte Carlo calculation at zero offset reproduces the deterministic summary and zone values.

## Known issues

- Only the saturation parameters and the cutoffs are varied. Porosity inputs (densities, shale point, NPHI matrix, gas correction), the GR baseline, temperature and depth are held at their base values, so the result understates the total uncertainty. The tab and the exports say so.
- The same draw applies to every well and zone, so wells move together; this gives the widest field spread. Per-well distributions are not available.
- HCPV is a column thickness per unit area in ft, not a volume. There is no area, contact or fluid-factor input.
- The tornado changes one parameter at a time and misses interactions; use the rank correlation as a cross-check.

## Installation

1. Download `Petrophyter_Setup_1.9.0_Build<build>.exe` from **Assets**.
2. Optionally verify it using `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash .\Petrophyter_Setup_1.9.0_Build<build>.exe -Algorithm SHA256
   ```

3. Run the installer and launch **Petrophyter** from the Start Menu. Installing over v1.8.0 upgrades it in place.

> Windows SmartScreen may appear because the installer is unsigned. Select **More info → Run anyway** only after confirming the SHA-256 hash.

## Assets
