# Petrophyter v1.7.3 (Build 20261011)

Petrophyter v1.7.3 is a usability release. The Curve Mapping page shows what each mapped curve holds, the Parameters window lists what changed since the last run and can put the last run's parameters back, and the plot engine selector moves under **Advanced**. **Results do not change**; only one warning is quieter.

## Changes

- **Curve Mapping detail.** A **Mapped curves** table under the curve choices shows, for GR, RHOB, NPHI, DT, RT and TVD, the unit from the file (the merge's for a merged well), the coverage (share of the well's samples with a value, in warning colour below 50 %), the range, and **Auto** (the curve detected from the curve names) or **Manual** (your choice; the tooltip names the curve detection would pick).
- **Changes since the last run, and Revert.** The Parameters window footer lists what changed since the active well's last run, for example "2 changes since the last run: m: 2 → 2.25; UPPER SAND · rw: 0.05 → 0.06"; the full list is in its tooltip and in the tooltip of the status bar's out-of-date label. A zone is listed only where it does not follow the well. **Revert to last run** restores the parameters that run used (project values, project zone values, the well's own and zone values, curve mapping, analysis scope) after a confirmation; project values are shared with other wells, and the confirmation says so. Formation tops are listed when they changed but are not reverted. A loaded session has no last run until the first run.
- **Plot engine under Advanced.** On the Log Display tab, **Plot Engine** sits in a row that the **Advanced** button shows; the button's tooltip names the engine in use.
- **Quieter Sw bound warning.** "Sw > 1.05 before clipping" needs at least 10 clean samples in the zone, so one clean sample in a shale zone no longer raises it. The Diagnostics counts are unchanged.

## Defaults and behaviour

- **Defaults confirmed:** gas crossover minimum 0.02 v/v and gas Vsh maximum 0.40 (both settable per well and zone), the zone GR baseline reach 0.75 of the well's GR range, and the automatic Rw bands Sw ≥ 0.8 (water) and Sw ≤ 0.5 (hydrocarbon).
- **Swirr limited to Sw is information, not a warning.** Limiting Swirr to the measured Sw follows from the kept `min(Swirr, Sw)` rule; it is not a fallback or a substitution.
- **Esc stops a running analysis** (as shipped in 1.7.1). **Run out-of-date wells** in the export check runs the wells but does not export by itself, so you see the run's outcome first.
- **Kept for later:** caliper bad-hole masking (opt-in and counted, when added), raising the porosity limits PHIT 0.45 / PHIE 0.40 (as a parameter with counts, if a field needs it), and a "use the saved results" choice for a changed source file (needs saved results).
- **Code signing is not planned for 1.7.x.** The installer stays unsigned; see the SmartScreen note under Installation.

## Quality

- The test suite has 1338 tests.

## Known issues

- The window title shows the active well, not the session file name.
- The Interactive log engine is verified on axes and items in automated tests; its drawing is checked by hand on a real display.
- The hint that a deviated well was assumed vertical rarely appears, because the LAS parser does not read inclination or deviation header entries. Map a TVD curve for deviated wells.

## Installation

1. Download `Petrophyter_Setup_1.7.3_Build20261011.exe` from **Assets**.
2. Optionally verify it using `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash .\Petrophyter_Setup_1.7.3_Build20261011.exe -Algorithm SHA256
   ```

3. Run the installer and launch **Petrophyter** from the Start Menu. Installing over v1.7.2 upgrades it in place.

> Windows SmartScreen may appear because the installer is unsigned. Select **More info → Run anyway** only after confirming the SHA-256 hash.
