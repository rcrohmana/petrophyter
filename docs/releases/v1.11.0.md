# Petrophyter v1.11.0 (Build 20261105)

Petrophyter v1.11.0 adds an LRLC Workbench for low-resistivity low-contrast pay: intervals that look porous and clean but read low resistivity, so the conventional Sw calls them wet. The Workbench screens for such intervals, shows the resistivity a sample needs to count as pay, flags water that is probably irreducible, and fits m and Rw on a Pickett plot. It is optional: **until you enable it, results, exports and saved sessions are the same as in v1.10.0.**

## New

- **Specialized menu** (after Analysis).
  - **LRLC Workbench…** (`Ctrl+L`) opens the new tab.
  - **Saturation Tools → Rt Cutoff Overlay…** opens the Rt cutoff section of the Workbench, and **Saturation Tools → Saturation-Height (Rt-independent Sw)…** opens the Saturation-Height tab.
- **LRLC Workbench tab** (after Saturation-Height). **Enable LRLC analysis** switches it on for the project; turning it off keeps every setting.
  - **Settings at four levels.** Project default, project zone, well default and well zone, the later level winning per setting. Each value shows where it comes from, with **Set here** and **Inherit**.
  - **Curve roles.** Mud resistivity, shallow resistivity, flushed-zone resistivity, photoelectric factor, shear sonic and a high-resolution resistivity curve, found by name or assigned by you. Flushed-zone (`RXO`, `MSFL`, `MCFL`) and shear sonic (`DTS`, `DTSM`, …) names are now recognised.
  - **Screening.** Six criteria per sample: low Rt, a hydrocarbon indication (the gas flag, or deep reading at or above shallow resistivity), porosity, shale volume, a low Rt/Rsh contrast and a high conventional Sw. They give `LRLC_SCORE` (criteria met) and `LRLC_FLAG` (a candidate: low Rt, porous and called wet, with enough supporting criteria). Porosity, Vsh and Sw use the zone's pay cutoffs; the Rt, contrast and score thresholds are design defaults to calibrate per field. A table per zone shows the candidate thickness, how much of it is not counted as pay, and the average porosity, Vsh, Sw and Rt.
  - **Rt cutoff.** `RT_CUT` is the Rt at which the selected Sw model, with the same inputs as the run, returns the target Sw (the zone's Sw cutoff unless you set one). It is computed per sample and as one value per zone over the pay, net reservoir or gross sand. It is an overlay only: it changes no Sw and no pay.
  - **Bulk volume water.** `BVW = PHIE × SW` and `WATER_FREE_FLAG`, net reservoir whose Sw is at or within a tolerance of Swirr (high Sw that may still produce without water). The **Buckles** plot shows Sw against porosity with constant-BVW lines and a table per zone.
  - **Pickett plot.** Rt against porosity on log-log axes, coloured by Vsh or zone, with iso-Sw lines from the current parameters. Wet points are proposed automatically (clean, porous, lowest Rt per porosity bin) and can be edited with **Add box**, **Remove box** and **Reset to automatic**. A robust fit gives m and a·Rw with their errors and a plain-words status. **Apply m** or **Apply m and Rw** writes the values to the active well, or to the selected zone of it, after a confirmation; a and n are never changed. Nothing is recomputed until you run the analysis.
  - **Remediation** lists the Rt each zone's Sw reads. No correction is available in this version, so Sw reads the measured Rt; automatic Rw and Rsh always read the measured Rt.
  - **Validation** points to the saturation-height comparison on the Saturation-Height tab.
- **Scientific references.** **Help → Scientific References…** lists the sources of every method by topic, with **Export BibTeX…**. Each Workbench tool has a **Method & Reference** box with its equation, assumptions, limits and citations. Citations whose details are not yet checked against the original are marked as such.
- **Data Browser.** **Analyze as LRLC candidate** in the context menu of a formation top opens the Workbench on that zone.
- **Log display.** With LRLC results the classic log gains a resistivity track after Sw (RT, and `RT_CUT` dashed), and the Pay Flags track shades the LRLC and water-free flags. The interactive log draws `RT_CUT` on its resistivity track and shades the same flags.
- **Exports.** `LRLC_SCORE`, `LRLC_FLAG`, `BVW`, `WATER_FREE_FLAG` and `RT_CUT` in the CSV, Excel and LAS results. LAS curve lines describe these curves, and the provenance block (Excel, CSV sidecar and LAS `~OTHER`) adds an "Rt corrections" line when LRLC analysis is on.

## Sessions

- A session is saved as format **2.5** only when LRLC analysis is on or configured. It adds the LRLC settings, each well's own settings and its curve role assignments. Any other session is saved as 2.4 or older as before.
- **A 2.5 session opens in v1.10.0 and older without the LRLC settings**, with the same Sw, pay and HCPV, because this version corrects no Rt. Saving it again there drops the LRLC settings.
- Opening a session saved by a newer Petrophyter of the same format generation now shows a notice that settings this version does not know were not loaded.

## Calculation changes

- None to existing results; every reference case is unchanged relative to v1.10.0. With LRLC analysis on, Sw, pay, HCPV, Swirr and permeability are identical to the run with it off; only the new columns are added. One new reference case covers screening, the Rt cutoff and a zone-specific threshold.

## Known issues

- The screening thresholds are design defaults, not published values; calibrate them per field.
- The hydrocarbon criterion needs the gas flag (gas correction on) or a shallow resistivity curve. Without either it is not evaluated, and the run says so.
- Deep reading at or above shallow resistivity is a weak hydrocarbon indicator with saline mud.
- The Pickett fit assumes the wet points really are water-bearing and Rw is constant; clay conduction biases m low. Manual wet-point boxes are not saved with the session.
- The Pickett ordinate is corrected to the Rw reference temperature with the well's current temperature settings, not those of the last run.
- Flushed-zone resistivity curves are not masked for non-positive values at load unless they are declared in ohm units; the LRLC tools ignore such values and count them.
- A few reference entries (Simandoux 1963, Poupon and Leveaux 1971, Morris and Biggs 1967, Crain's handbook and the sources of tools not yet shipped) are still marked "to be confirmed": no primary record of them could be checked yet.

## Installation

1. Download `Petrophyter_Setup_1.11.0_Build20261105.exe` from **Assets**.
2. Optionally verify it using `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash .\Petrophyter_Setup_1.11.0_Build20261105.exe -Algorithm SHA256
   ```

3. Run the installer and launch **Petrophyter** from the Start Menu. Installing over v1.10.0 upgrades it in place.

> Windows SmartScreen may appear because the installer is unsigned. Select **More info → Run anyway** only after confirming the SHA-256 hash.
