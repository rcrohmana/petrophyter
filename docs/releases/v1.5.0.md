# Petrophyter v1.5.0 (Build 20260814)

Petrophyter v1.5.0 is a reliability-focused release that hardens petrophysical calculations, file handling, saved sessions, exports, diagnostics, theming, and application logging. It includes all 65 commits since v1.4.0.

## Highlights

### Petrophysics and diagnostics

- Added explicit, configurable neutron matrix responses for quartz, limestone, and dolomite.
- Persisted neutron matrix selections and custom values in session files.
- Added Waxman-Smits and Dual-Water results to water-saturation diagnostics.
- Added visible diagnostic warnings for saturation points where a numerical solver finds no root or fails.
- Added strict validation and safe defaults for petrophysical formula parameters.
- Improved PHIE method selection, fallback behavior, and handling of unavailable curves.

### Data integrity and file handling

- Hardened LAS, core, and formation-top parsers with clean per-load state resets and caller-visible parsing errors.
- Added UTF-8-first LAS decoding with resilient fallback behavior.
- Resolved multiple depth mnemonics consistently across parsing, QC, statistics, merge, and export workflows.
- Sorted depth data, refined formation overlap handling, and aligned external series safely for statistics.
- Strengthened multi-LAS merge input checks, gap handling, curve metadata, and exported LAS mnemonics.
- Added numeric dtype checks and safer null replacement.
- Added atomic session and export writes to reduce the risk of partial or corrupted files.
- Made analysis-result updates atomic and cleared derived state when source LAS data changes.

### UI, visualization, and sessions

- Restored supported parameter groups more completely when loading sessions.
- Added parameter-widget setters for consistent UI restoration.
- Displayed every available water-saturation curve in the composite log.
- Improved Summary and QC handling for NaN, missing, and numeric values.
- Reset tabs reliably when QC or analysis results are unavailable.
- Standardized theme APIs and refreshed diagnostic plots, histograms, QC charts, summary charts, and interactive log plots immediately after theme changes.
- Sanitized technical error details shown in UI messages while retaining actionable diagnostics in application logs.

### Logging, documentation, and quality

- Added rotating application log files with resilient fallback behavior and startup initialization.
- Reorganized project documentation into focused guides for installation, data formats, calculations, sessions, visualization/export, troubleshooting, building, version history, and licensing.
- Removed committed bytecode and expanded ignore rules for build output, caches, logs, local agent files, and sensitive configuration.
- Hardened Windows packaging by using the selected Conda interpreter, including forwarded MKL runtime dependencies, removing stale duplicate Qt MSVC runtimes, and making registry writes follow the selected admin/current-user install mode.
- Added extensive regression tests for I/O, LAS utilities, formation tops, core data, QC, statistics, petrophysics, services, models, themes, UI state, and build configuration.

## Installation

1. Download `Petrophyter_Setup_1.5.0_Build20260814.exe` from **Assets**.
2. Optionally verify it using `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash .\Petrophyter_Setup_1.5.0_Build20260814.exe -Algorithm SHA256
   ```

3. Run the installer and launch **Petrophyter** from the Start Menu.

> Windows SmartScreen may appear because the installer is unsigned. Select **More info → Run anyway** only after confirming the SHA-256 hash.
