# Petrophyter v1.6.0 (Build 20261009)

Petrophyter v1.6.0 is an interface release. The left sidebar is replaced by a desktop-standard layout: a menu bar and toolbar, a read-only Data Browser, and a modeless Parameters window. A token-based design system now drives the Light and Dark themes. Calculation results are unchanged from v1.5.0, and saved sessions from v1.5.0 open as before. The release includes all 26 commits since v1.5.0.

## Highlights

### New interface

- **Menu bar and toolbar.** File, Session, Analysis, Parameters, Corrections, View, and Help menus replace the sidebar buttons. Common actions have keyboard shortcuts.
- **Data Browser.** A read-only tree lists the loaded LAS files (with row counts), curves, formation tops, and core data. You can hide it from the View menu.
- **Parameters window.** All analysis settings live in one modeless window with ten pages, so you can keep it open while you review results.
- **Merge LAS Files dialog.** A dedicated dialog replaces the sidebar merge block.
- **Status bar.** Shows analysis progress, a QC status chip, and a stale-results indicator when parameters change after a run.
- **Notification banners.** Non-blocking messages replace informational pop-ups.
- **Saved layout.** Window size, panel layout, and Parameters window position are restored on the next launch.

### Design system and visuals

- Light and Dark themes are rendered from a single set of design tokens, so colors, spacing, and typography are consistent across every tab, dialog, table, and chart.
- A bundled, theme-aware Lucide icon set (ISC license) replaces emoji and mixed icon styles. Icons recolor instantly when the theme changes.
- Result tables share one table model with consistent decimals and alignment.
- Plot text, axes, and toolbars follow the active theme, and chart text is readable in Dark mode.

### Fixes

- The Interactive log now opens fitted to the data's depth range instead of starting at depth 0, which had squeezed the curves into the bottom of the tracks.
- Correct per-file row counts after a LAS merge.
- The stale-results indicator clears when new data is loaded.
- Cancelling or failing a merge preparation no longer leaves the merge state inconsistent.

### Build, packaging, and quality

- `pyqtgraph` and `PyOpenGL` are declared in `requirements.txt` for the Interactive log engine.
- Build scripts default to the `mldl` Conda environment used for release builds.
- The installer now includes the `LICENSE`, `LICENSE-APACHE-2.0`, `LICENSE-GPL-3.0`, and `NOTICE` files.
- The user guide is rewritten for the new interface.
- Automated design-system compliance tests prevent hard-coded colors, inline styles, emoji, and informational modals. The suite has 360 tests in total.

## Known issues

These are scheduled for a follow-up release:

- **File → New Project**, the Open actions, and Load Session stay enabled while an analysis is running.
- Spin boxes follow the Windows regional format. On systems that use a decimal comma, they show "0,50" while tables show "0.50".
- On the Parameters → Cutoffs page, the slider rows have a slightly offset background strip. The Core Matching page shows a similar strip in Dark mode.
- In the Diagnostics porosity table, the Method label "PHIE_DN (selected)" can be truncated.
- Some Diagnostics chart titles use bold text while the other charts do not.

## Installation

1. Download `Petrophyter_Setup_1.6.0_Build20261009.exe` from **Assets**.
2. Optionally verify it using `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash .\Petrophyter_Setup_1.6.0_Build20261009.exe -Algorithm SHA256
   ```

3. Run the installer and launch **Petrophyter** from the Start Menu. Installing over v1.5.0 upgrades it in place.

> Windows SmartScreen may appear because the installer is unsigned. Select **More info → Run anyway** only after confirming the SHA-256 hash.
