# Petrophyter v1.7.0 (Build 20261010)

Petrophyter v1.7.0 turns a single-well tool into a multi-well project. You can load many wells at once, set parameters per well and per formation zone, run every well in one click, assign one tops or core file to many wells, and save the whole project in one session. Formation-temperature correction now covers Rsh and bound water and follows true vertical depth. A few calculation fixes change results in specific cases; see [Calculation changes](#calculation-changes). The release includes the 48 commits since v1.6.0.

## Highlights

### Multi-well projects

- **Load many wells.** **Open LAS File(s)…** reads several files in the background and shows a **Load Summary** that groups them by well identity (UWI, API, or name). Files of one well are merged; files of different wells never are.
- **Per-well data.** The Data Browser has one root per well and the toolbar has a well selector. Tops, core data, analysis scope, and results belong to each well.
- **Run All Wells** (`Ctrl+Shift+R`) analyses every well in the background and skips wells whose parameters have not changed. **Run Analysis** (`F5`) reruns the active well while other wells keep running.
- **Multi-well outputs.** A Zones pay table, a Wells table with a field total, export of all wells to Excel, CSV, or LAS, and optional zone shading on the log.

### Parameter scopes and zones

- Set parameters for the project, a well, a formation zone, or a well · zone; the most specific entry wins. The Parameters window has a scope bar, a mode menu per field, and a **Zones** grid.
- Each zone runs with its own a, m, n, matrix and shale points, Rw, Rsh, and cutoffs. Auto estimates use only that zone's samples and fall back to the next scope when a zone is too thin. The source of every value is shown.
- Shale point **Auto** per well and per zone, lithology presets that stay linked at well and zone scopes, and Wyllie-Rose permeability calibration on the edited scope.
- **Zone diagnostics.** Zones with no gross, no net reservoir, or no net pay are marked in the Summary, and the Zones grid marks the cutoff that caused it.

### Multi-well tops and core import

- One tops or core file with a well column is assigned to the loaded wells in a preview dialog. You check how the file was read, map columns, set the depth unit, match each file well to a loaded well, and choose Keep or Replace. Nothing changes until you confirm.
- Tops and core tables can be `.xlsx`, tab-, comma-, semicolon-, or pipe-delimited, in UTF-8 or Windows-1252, with comment lines, a unit row, and decimal commas. Every excluded row is reported with its line number.

### Rw, Rsh, and formation temperature

- Rw and Rsh each have an **Auto** checkbox, and manual values are used as entered.
- Temperature correction (Arps) now covers Rw, an auto Rsh, a manual Rsh with its own reference temperature, and the Dual-Water Rwb. Waxman-Smits B can be computed from temperature (Juhasz, 1981).
- Temperature follows true vertical depth from a mapped **TVD** curve when available, with a datum depth and a live readout of the temperature at the log ends. All temperature options are off by default.

### Sessions

- Session format 2.0 and 2.1 store the whole project, including how each well's tops and core data were imported, and re-read the files on load. Restoring runs in the background with progress in the status bar and can be cancelled.
- Format 1.x sessions still load. **Sessions saved by v1.7.0 cannot be opened by v1.6.0 or older.**

### Interface, fixes, and performance

- LAS loading reads more header fields (UWI, API, elevations, BHT, TD) and converts neutron in percent, density in kg/m³, and sonic in µs/m at load.
- **Installer fix.** The installer now bundles the Intel MKL libraries that scipy needs. On a PC without Anaconda, v1.6.0 could close with "Intel oneMKL FATAL ERROR: Cannot load mkl_intel_thread.2.dll" when a feature used scipy's linear algebra, for example permeability calibration from core.
- Opening files, Load Session, merging, and running are disabled while LAS files load. Quitting during an analysis, a load, or a session restore asks for confirmation.
- The v1.6.0 known issues are fixed: number fields use the English (US) format regardless of the Windows regional setting, the Parameters pages have no background strips, the Diagnostics method name is not truncated, and chart titles use normal weight. Every menu action has an icon.
- The Waxman-Smits and Dual-Water solvers are vectorised (about 10 ms instead of 0.7 s for 10,000 samples), and the result tabs refresh once per load.
- The test suite has 891 tests.

## Calculation changes

These fixes can change results compared with v1.6.0:

- A manual Rsh is used as entered; v1.6.0 replaced it with the estimate from the data.
- Auto Rw uses the Rwa method on clean (Vsh < 0.3), porous samples instead of raw NPHI and the lowest RT quartile. When no estimate exists, for example on shale-only data, the entered Rw is used with a warning.
- Calculate Rw/Rsh and VShale use the same GR baseline rule as the analysis (P5/P95 with at least 20 API separation).
- With several VShale methods selected, the VSH column holds the series used downstream.
- Curves in non-standard units are converted before the analysis.

On the reference test cases, results with default settings are unchanged from v1.6.0 except for shale-only data with auto Rw. Session files from v1.6.0 or older that store Rw ≤ 0.01 load with Rw in Auto mode.

## Known issues

- The hint that a deviated well was assumed vertical rarely appears, because the LAS parser does not read inclination or deviation header entries. Map a TVD curve for deviated wells.
- Core porosity scale (percent or fraction) is decided per well from the median. For very tight wells, check the **Porosity** column in the import dialog and override it if needed.
- The multi-well import dialog is wide (about 1180 px); on small screens its well table scrolls horizontally.

## Installation

1. Download `Petrophyter_Setup_1.7.0_Build20261010.exe` from **Assets**.
2. Optionally verify it using `SHA256SUMS.txt`:

   ```powershell
   Get-FileHash .\Petrophyter_Setup_1.7.0_Build20261010.exe -Algorithm SHA256
   ```

3. Run the installer and launch **Petrophyter** from the Start Menu. Installing over v1.6.0 upgrades it in place.

> Windows SmartScreen may appear because the installer is unsigned. Select **More info → Run anyway** only after confirming the SHA-256 hash.
