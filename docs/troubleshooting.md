# Troubleshooting

## LAS File Does Not Load

- Check the file encoding; UTF-8 is recommended.
- Verify that the file uses LAS version 1.2 or 2.0.

## Calculations Seem Wrong

- Verify the input curve units in the LAS header.
- Check the shale parameter values.
- Ensure that depth uses the correct unit, feet or meters.
